# 一期单猫界面与稳定关联

> **部分被取代。** 「不加入猫咪切换和多猫管理流程」这部分由 [数据存到服务器 MySQL，Dexie 退成构建期开关](0003-server-backed-storage.md) 取代：数据模型和端口已经改成多猫就绪的，界面暂时仍然只用第一只。
> 「用稳定 ID 并让体重记录和快照保留猫咪关联」这部分继续有效，正是它让这次改造不用重建历史数据。

一期界面只支持一只猫，不加入猫咪切换和多猫管理流程；猫咪、体重记录、食品和计算快照仍使用稳定 ID，并让体重记录和快照保留猫咪关联，为后续扩展多猫保留数据空间。这样可以控制首期界面复杂度，同时避免未来扩展时重建历史数据。
