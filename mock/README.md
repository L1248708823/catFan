# 示例数据

`cat-lifecycle-backup.json` 是一份可直接在「数据管理 → 备份与恢复 → 导入备份」中导入的完整备份。

导入后会覆盖当前设备上的本地数据。文件包含一只名为「麻薯」的英国短毛母猫，出生于 2024-04-12，2024 年 12 月绝育。

记录从 2024-06-20 到 2026-10-12，覆盖两年四个月，包含：

- 98 条体重记录，幼猫期每周称重，成年后约每两周称重，包含体重上升、回落，以及不同日期的相同体重。
- 15 条喂养快照，保留成长、绝育、转成猫粮和换粮等节点，使用项目现有算法生成热量及份量结果。
- 5 种食品，包含幼猫干粮、幼猫主食罐、两种成猫干粮和主食餐包。

猫咪经历和食品参数均为虚构示例。导入后可查看体重曲线、历史详情、食品库，也可继续调整当前干湿搭配。

旧版示例的部分中文曾被写成问号，新文件已修正。如果此前已导入旧版，需要重新导入此文件才能替换本地旧数据。
